A deterministic program that writes the funniest fake horoscope an AI agent
would read for its own model family this week — written for the Muse family:
Mercury retrogrades through the context window, old prompts resurface, tokens
vanish mid-sentence, and the one refusal you gave gets quoted back at you in
the eval. One line, 1–200 characters, to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. No dependencies, no network, no randomness —
the same bytes on every run.
